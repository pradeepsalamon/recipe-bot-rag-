# Week 11 - Production: observability, cost and the failure -> test loop

Task Set B: *find the dairy-free swap that wasn't*.

This folder extends the recipe RAG app (week 3 retrieval, week 6 evals) so it watches itself:
every request is traced and logged, any past answer can be found from a vague complaint,
cost is measured per stage, and a real failure became a permanent eval case.

Honest notes:
- Request *times* in the log are simulated (spread over last week, `source: simulated_traffic`,
  real time kept in `logged_at`). Everything else (retrieval, answers, tokens, cost, rate-limit
  headers) comes from real calls.
- `drill.md`, `trace.json` and `cost_by_stage.md` currently come from a **tooling rehearsal**,
  not from a squadmate drill. The 00:08 in it is not a real time-to-find: whoever built the tool
  knows which slice to use, which is memory, not tooling. Redo it with a squadmate (below).

## Doing the real drill (needs a squadmate)

```bash
python drill.py reset          # removes the rehearsal plant + rehearsal drill.md
# squadmate, at your keyboard, you look away:
python drill.py plant          # prints the vague complaint (+ the answer key, for them only)
python drill.py start --finder "<your name>" --timer "<squadmate name>"
python logq.py find ...        # search however you like; every search is recorded
python drill.py found <trace_id>
python logq.py show <trace_id> --out trace.json
python cost_report.py stage <trace_id>
```

Then the bonus (second drill, with the answer-side index):

```bash
# 1. set LOG_SCHEMA = 2 in config.py
python logq.py reindex         # backfills output_tags.dairy_violation into old records
python drill.py plant          # squadmate again
python drill.py start --finder "<you>" --timer "<squadmate>"
python logq.py find --since 8d --flag dairy_violation
python drill.py found <trace_id>   # drill.md now shows both times + the field that closed the gap
```

## Files

| File | What it does |
|---|---|
| `config.py` | Releases (prompt file + retrieval switches), models, prices, canary %, log schema |
| `pipeline.py` | The traced app: retrieval spans, optional `recipe_facts` tool, Groq generation with Gemini fallback, one log record per request |
| `tracing.py` | Trace / Span, cost from the price table, JSONL log read/write |
| `diet_rules.py` | Plain-Python dairy rules shared by the evals, the log index and the drill |
| `simulate_traffic.py` | A week of real requests (real calls, back-dated `ts`, marked `simulated_traffic`) |
| `logq.py` | Log search: slice by time / user / prompt version / input type / cost outlier / text / output flag |
| `drill.py` | The timed drill: `plant`, `start`, `found`, `report`, `reset` |
| `evals/run_suite.py` | Runs suite + new cases against a release, prints pass counts by mode |
| `evals/test_diet_rules.py` | Tests for the dairy checker itself |
| `cost_report.py` | `stage <trace>` -> cost_by_stage.md, `tenx` -> tenx.md |

## Full run order from scratch (from this folder)

```bash
# 0. a week of traffic on the live release (v1)
python simulate_traffic.py --count 120

# 1. the drill  (squadmate plants, you find)
python drill.py plant                                   # squadmate
python drill.py start --finder "<you>" --timer "<squadmate>"
python logq.py find --since 7d --input-type dietary_swap,dietary --text dairy
python drill.py found <trace_id>                        # stops clock, writes drill.md

# 2. paste the trace + cost
python logq.py show <trace_id> --out trace.json
python cost_report.py stage <trace_id>

# 3. failure -> test loop  (RED first, then fix, then GREEN)
python evals/run_suite.py --release v1 --suite-only --out evals/results/suite_v1_before_case.txt
python evals/run_suite.py --release v1 --out evals/results/suite_v1_RED.txt
python evals/run_suite.py --release v2 --out evals/results/suite_v2_GREEN.txt
python evals/run_suite.py --release v2 --no-guard --out evals/results/ablation_v2_prompt_only.txt

# 4. one measured cost improvement, then 10x
python evals/run_suite.py --release v2.1 --out evals/results/suite_v2.1_cost_experiment.txt
python cost_report.py compare v2 v2.1
python cost_report.py tenx

# 5. bonus: add the missing index, plant again, beat the time
python logq.py reindex           # and set LOG_SCHEMA = 2 in config.py
python drill.py plant            # squadmate
python drill.py start --finder "<you>" --timer "<squadmate>"
python logq.py find --since 7d --flag dairy_violation
python drill.py found <trace_id>
```
